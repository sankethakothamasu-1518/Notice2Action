REST API reference

Every screen above is driven by these JSON endpoints.

MethodEndpointPurpose
GET/api/healthService + database health, OCR availability
GET/api/statsDashboard counters
GET/api/notices?status=&q=&limit=&offset=List notices (search + filter)
GET/api/notices/:idFull analysis of one notice
POST/api/noticesCreate notice — multipart file or JSON {text,title,uploaded_by,ref_date}
POST/api/notices/:id/reanalyzeRe-run NLP on stored text
PATCH/api/notices/:idRename a notice
DELETE/api/notices/:idDelete notice + all derived rows
GET/api/deadlines?upcoming=trueAll deadlines with days-left
GET/api/checklist?status=open|done&notice_id=Checklist items
POST/api/notices/:id/checklistAdd a manual task
PATCH/api/checklist/:idTick / untick / edit a task
DELETE/api/checklist/:idDelete a task
POST/api/analyzeStateless analysis (nothing saved)
GET/POST/api/usersList / create users
